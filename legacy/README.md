# Legacy tcr_design files

`tcr_design_v1/` preserves the files that were present at the root of the predecessor `aapupu/tcr_design` repository before it became the `tcr_mhc_convert` monorepo.

They remain here for provenance and reproducibility. New code should use `MHCtransform/` and `TCRtransform/`; the legacy tables and scripts are not part of the current package APIs and may use older sequence definitions.
